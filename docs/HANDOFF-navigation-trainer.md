## Как продолжать и проверять

Node.js **24+**, установленный Chrome. Зависимости уже находятся в изолированном Node workspace и подключены к `site/node_modules` junction. Node 22 не подходит серверу (SQLite). На другой машине установить зависимости из lockfile.

Из `site/`:

```bash
npm run build
npm test
HOST=127.0.0.1 PORT=4174 npm run dev
```

В другом терминале из `site/`:

```bash
TEST_BASE_URL=http://127.0.0.1:4174 node tests/navigation-trainer.mjs
TEST_BASE_URL=http://127.0.0.1:4174 node tests/release-a.mjs
TEST_BASE_URL=http://127.0.0.1:4174 npm run verify
```

Проверки desktop/mobile, DE/RU/UK/TR, normal/reduced motion, обычные переходы/повторные клики, прямой hash, назад/вперёд, ручная прокрутка, фото и Instagram, автономный файл без сетевых запросов. Открыть `http://127.0.0.1:4174/ru/` либо сгенерированный `site/dist/ak-loewen-valset-v1.html`.
