# Release 3 — Telegram bot

## Назначение

Release 3 — текущая рабочая версия Telegram-бота AK LÖWEN. Она основана на утверждённом Release 2, но не заменяет и не изменяет Production-сайт.

## Статус

**WIP / Preview. Не готово к Production.**

Код и подготовительные материалы сохранены в ветке `release-3`. Финальная активация и полный набор проверок ещё не завершены.

## Готово

- Telegram-бот с языками DE/RU/UK/TR.
- Немецкий язык по умолчанию и отдельное меню выбора языка.
- Кнопочная навигация, FAQ, запись на тренировку, статусы и действия сотрудников.
- Защищённые webhook/worker, Redis/outbox и runtime-валидация.
- Privacy notice опубликован на Preview.
- Подготовлена проверка членства сотрудника в заданной Telegram-группе через `getChatMember`.
- Подготовлены инструкции по Preview-активации.

## Не завершено

- Не выбрана и не привязана окончательная Telegram-группа тренеров.
- Не подтверждён окончательный список сотрудников с правами подтверждения/переноса/отмены.
- Модуль проверки staff membership ещё нужно подключить к обработчику.
- Не завершена настройка minute-trigger для worker.
- Не завершена финальная Preview runtime-конфигурация.
- Финальные tests/lint/build для текущего состояния не запускались.
- Реальный end-to-end Preview-flow ещё не подтверждён.

## Порядок завершения

1. Настроить trainer group и staff access.
2. Подключить staff membership validation.
3. Настроить защищённый scheduler/worker trigger.
4. Завершить Preview runtime variables.
5. Выполнить финальные tests/lint/build.
6. Выполнить один реальный Preview booking flow.
7. Только после успешной проверки принимать отдельное решение о Production.

## Нумерация проекта

- **Release 2** — утверждённая версия сайта.
- **Release 3** — текущая Telegram-доработка.

Commit SHA, старые feature-ветки и служебные имена используются только как техническая история и не являются названиями версий проекта.
